## Main Android project

### IseuSchedule

IseuSchedule is an Android application for university schedule and student cabinet flows.

It includes:

* student and teacher schedule flows;
* student cabinet login and registration;
* OCR-assisted captcha handling;
* local schedule caching;
* offline behavior;
* academic results;
* local lesson notifications;
* state restoration after network changes and device reboot.

My work in this project covers Android architecture, Compose UI, data layer, local persistence, network handling, OCR flow, notification logic and product behavior.

Repository: https://github.com/YARIGAVGAN/IseuSchedule_V2
